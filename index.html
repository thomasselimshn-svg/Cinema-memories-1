Comment l'imprimer
  1. Enregistre le PDF dans Fichiers.
  2. Ouvre-le dans Fichiers ou dans l'application de ton imprimante.
  3. Choisis l'imprimante Bluetooth déjà associée.
  4. Si l'application le demande, règle le papier sur 80 mm.
  5. Vérifie que l'échelle est à 100 % (pas d'ajustement à une page A4).
  6. Lance l'impression.

Ce site ne se connecte pas à l'imprimante : il fournit un PDF standard. Le résultat dépend de l'application et du modèle d'imprimante.
